@changwei1006 并非 bug。
Windows 保留设备名冲突 + 跨平台 Shell 混用导致的。 在 Linux 中，丢弃输出通常写向/dev/null。在Windows中，有些代码或配置文件为了达到同样的效果，被错误地硬编码为写入名为 nul 的路径。因为名字是保留字，Windows 资源管理器（图形界面）在处理它时会发生混淆，导致无法直接删除。
